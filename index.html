▸ Formulas (from “Formula for Climate Settings”)
Season mapping — Northern: Winter=DJF, Spring=MAM, Summer=JJA, Autumn=SON / Southern: flipped
Temperature Night/Day — seasonal mean of monthly daily min / max
Temperature Deviation — max(2.5, σ(monthly)×1.5); if mean-extreme rows exist, also |daily − extreme| / 1.5, take the larger
Clouds Amount — 100 − sunshine %
Clouds Chance — min(100, Clouds Amount × 1.5)
Clouds Amount Deviation — clamp(15 + σ(monthly cloud %), 15, 30)
Precipitation Chance (v3, default) — realistic wet-time: monthly mm ÷ (rate × hours in month) × 3, rate = (0.6 + 1.4×warmth) × (1 + 3.5×convectivity) mm/h (light snow 0.6 → warm rain 2.0 → convective downpour ~9). CS2 consumes Chance roughly as share-of-time and official prefabs already over-rain, so this anchors to physics (×3 keeps weather present in gameplay; set Chance × to 33% for strict realism). The Chance ×% box scales any model to taste
Precipitation Chance (v2) — days × factor × (1 − 0.5 × convectivity); factor 5.5 (≥0.1 mm counting) / 6.5 (≥0.25 mm) restores the SF/Tampere prefab anchors; v1: days × 6
Convectivity — warm((T−15)/10) × sunny((sun% − 40)/30), each clamped 0–1. Hot + sunny-despite-rain = brief afternoon thunderstorms (Charleston, Miami) get up to −50% Chance; overcast monsoon/frontal rain (Seoul jangma, London) is untouched
Precipitation Amount (v2) — intensity soft-knee: mm/day above 11 counts half (a few torrential events skew the mean), then × 6.25; v1: raw × 6.25
Precip. Amount Deviation — clamp(Amount × 0.25, 10, 30)
Turbulence — min(0.8, max(0.1, intensity/25 × temp_factor × (1 + 0.5 × convectivity))), temp_factor = clamp((daily mean + 5)/15, 0.2, 1.0) — convective storm cells cycle weather faster
Start Time — season start as a fraction of the year (Northern: Spring = Mar 1 ≈ 0.162 … / Southern: flipped)
Max Sun Elevation — clamp(90 − |lat| + 23.44, 45, 90); clamp start defaults to 15° below that
Aurora Chance / Strength — latitude-based estimate: 0 below ~50°, scaling to ~68°; suppressed during bright high-latitude summers
Freezing Temperature — default 0 °C (the rain ↔ snow threshold); Default Weather Prefab / Weathers are game-side selections, keep defaults
Validated against the official CS2 San Francisco prefab (within ±10%). Tampere’s prefab is hand-tuned for aurora gameplay and snow visuals, so real-climate values intentionally differ — this app computes the real-climate-accurate values.
