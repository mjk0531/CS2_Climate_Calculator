▸ How these values are derived
The values are not fitted with formulas — they are solved. CS2's own curve generator (ClimatePrefab.RebuildCloudinessCurves / RebuildPrecipitationCurves, decompiled from Game.dll) is reimplemented here exactly, including Unity's simplex noise, its gaussian draws and its animation curves. The app then searches for the season parameters whose simulated year matches the real climate, and shows you the simulated result next to the target on every card.
What the game does — per game-day it draws gaussian(Amount ± Deviation), adds noise · Turbulence, then attenuates by 1 − (noise − Chance)·2, and finally fades precipitation out below 0.7 / 0.4 cloudiness, forcing it to zero below 0.2
Why vanilla feels so wet — rain only stops completely once noise ≥ Chance + 0.5. The game's default (Chance 30) precipitates 54% of the year; even Chance 0 rains a third of the time unless the clouds are thin
Sunshine vs rain — the game calls it sunny when cloudiness ≤ 0.5 and precipitation == 0, so drizzle eats sunshine. Real sunshine and real rain frequency cannot both be met; the selector above the cards decides which one wins
Temperature — the season means are used directly (the game draws around them). Deviation is the 90th-percentile daily spread the game expects: σ / 0.78, with σ from the mean monthly extremes (|extreme − daily| / 2.04)
Water — Precipitation Amount is solved so the mean precipitation value equals the real rainfall rate, reading precipitation 1.0 = 10 mm/h. Deviation tracks Amount, since rain intensity is close to exponential
Random Seed matters — a game year is only 12 days, so a season holds just three random draws: the same parameters swing between 15% and 85% sunshine depending on the seed. The app scans seeds, picks the one that lands closest to the real climate, and refits the parameters for it. Use the seed it gives you.
Start Time — season start as a fraction of the year (Northern: Spring = Mar 1 ≈ 0.162 … / Southern: flipped)
Max Sun Elevation — clamp(90 − |lat| + 23.44, 45, 90); clamp start defaults to 15° below that
Aurora Chance / Strength — latitude-based estimate: 0 below ~50°, scaling to ~68°; suppressed during bright high-latitude summers
Freezing Temperature — default 0 °C (the rain ↔ snow threshold); Default Weather Prefab / Weathers are game-side selections, keep defaults
The official prefabs sit far on the wet side of this trade-off, which is why vanilla maps rain so much. Tampere's is additionally hand-tuned for aurora gameplay and snow visuals.
